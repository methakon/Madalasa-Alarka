# Community Code of Conduct

Madalasa–Alarka concerns potentially sensitive child-safety technology. All contributors, maintainers and participants must engage respectfully and safeguard minors, guardians and researchers.

Expected: respectful technical disagreement, inclusive collaboration, accurate evidence, confidentiality for children and vulnerable people, least-privilege access, and good-faith security reporting.

Prohibited: harassment, threats, discriminatory abuse, doxxing, sharing private location, coercive monitoring, posting real child/guardian identifiers, unauthorized surveillance, credential leaks, or publishing exploitation details before coordinated remediation.

Moderators may remove content, restrict participation, or report credible threats as appropriate. A confidential enforcement contact and backup **must be designated by the repository owner before public community onboarding**. Until then, use GitHub moderation controls for public conduct issues, but never post sensitive safety complaints publicly. Security flaws belong in [SECURITY.md](SECURITY.md). Reports concerning immediate threats to children require appropriate emergency channels, not GitHub discussions.

Actions are assessed proportionately with confidentiality, opportunity for response where safe, and review of conflicts of interest. This policy does not authorize access to child information.
