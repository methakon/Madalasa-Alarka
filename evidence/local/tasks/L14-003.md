## Acceptance

> "Only configured owner can grant roles"

1. **Owner Allowlist Binding:** PostgreSQL `ap_m1.owner_identity_allowlist` stores `(issuer, subject)`. The function `ap_m1.admin_is_owner(uuid)` matches against verified Google OIDC issuer + sub from `parent_principals`.
2. **Access Queue Isolation:** `GET /v1/admin/owner/access-requests` strictly checks `ap_m1.has_admin_permission('OWNER_MANAGE')` and `ap_m1.admin_is_owner(ap_m1.ctx_admin())`. Non-owners receive `403 FORBIDDEN`.
3. **Role Decision Enforcement:** `POST /v1/admin/owner/access-requests/{requestId}/decision` executes `ap_m1.decide_admin_request()`, requiring `OWNER_MANAGE` and `admin_is_owner`. If caller is non-owner or lacks MFA, PostgreSQL raises error code `42501` (`owner MFA required`).
4. **Data Minimization & Zero Minor Visibility:** Owner and admin identities have zero access to raw minor location observations, media sessions, or device credentials (enforced by default-deny RLS and table grant boundaries).
