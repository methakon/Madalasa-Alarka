## What exists

`admin-web/` is a separate Vite + React 19 + TypeScript project with `src/api.ts`,
`src/fixtures.ts`, `src/main.tsx`, `src/styles.css` and `tests/security.test.mjs`, plus a
deploy contract test (`deploy/x402/admin/test-deploy.mjs`). `npm run dev` binds
`vite --host 127.0.0.1`, so the shell never listens off-host.
