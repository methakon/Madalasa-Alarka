  (4 tests) asserting the Theme C contract rather than trusting it.

## Acceptance

> "Screens visually consistent and English-only initially"

- Visual consistency: the nine palette colours are asserted against their exact ARGB
  values and against each other for distinguishability, so a screen cannot drift from the
  contract without failing the build. The typography scale is asserted to be strictly
  ascending, non-repeating and never below the readable minimum.
- English-only: any `values-<language>` resource directory (`hi`, `bn`, `bn-rIN`, …) fails
  the test, while API (`values-v31`) and UI-mode (`values-night`) qualifiers stay allowed.
  `values/strings.xml` is asserted free of Devanagari, Bengali, Tamil, Telugu, Arabic and
  CJK code points.
- Icon resources: the adaptive icon declares background, foreground and monochrome layers,
  every referenced drawable resolves on disk, all five density buckets ship a non-trivial
  PNG, and the manifest binds `@mipmap/ic_launcher` with no synthetic placeholder.
