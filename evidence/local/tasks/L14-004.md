## Acceptance

> "Unapproved login cannot query admin APIs"

1. **Self-Status and Profile Boundary:**
   - Evaluates administrator account state using `ma::admin::evaluate_access_state(...)`.
   - Any Google login that has not been approved by the root owner evaluates to `NO_ACCESS` state with empty `role_codes` (`[]`), `mfa_active = false`, and `allowed_actions = ["REQUEST_ACCESS"]` (only when email is verified and no prior request is pending).
2. **Fail-Closed Gate for Admin APIs:**
   - Any query or mutation to operational administrator endpoints (`/v1/admin/owner/*`, `/v1/admin/support/*`, `/v1/admin/faqs/*`, `/v1/admin/billing/*`, `/v1/admin/audit/*`) by an unapproved applicant in `NO_ACCESS` state is denied with `403 FORBIDDEN` (enforced by `ap_m1.has_admin_permission(...)` which requires `a.state = 'ACTIVE'` and explicit role grants).
   - Inactive, suspended, or revoked sessions fail closed.
3. **Data Minimization:**
   - Profile collection collects no date of birth, gender, or physical postal address. DOB/gender attempts fail with `422 VALIDATION_FAILED`.
   - No visibility into child location or media streams.
