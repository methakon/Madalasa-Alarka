## Acceptance

> "No live Google charge or API credential"

1. **Synthetic Token Architecture:** All purchase tokens are generated with the enforced prefix `synthetic-play:sub:<family_id>:<child_id>:<sku>:<nonce>`. Any token without this prefix fails closed with `None` or `ValueError`.
2. **Offline Google Play Developer API Simulator:** Simulates `SubscriptionPurchaseV2` resource model for `plan_monthly` (₹99/mo standard, ₹50/mo founding), `plan_yearly` (₹999/yr standard, ₹500/yr founding), and `addon_viewer_100d` (₹100 once for 100 days). Emits `testPurchase = {"synthetic": true, "charge_amount": 0}` with zero financial charge.
3. **Cloud Pub/Sub RTDN Webhook Emitter & Parser:** Emits and parses Real-Time Developer Notification envelopes with Base64 payload decoding, verifying notification types `PURCHASED`, `RENEWED`, `CANCELED`, and `EXPIRED`.
4. **Lifecycle State Machine:** Verifies subscription state transitions `ACTIVE` → `CANCELED` → `RENEWED` → `EXPIRED`. Expired subscriptions cannot be renewed.
